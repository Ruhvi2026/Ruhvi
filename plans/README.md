# GSD Plans Directory

This directory stores long-term milestone roadmaps, feature specs, and phase execution plans.

## Workflow Rules
1. Every major feature starts with a phased plan modeled on `.gsd/templates/GSD_PLAN_TEMPLATE.md`.
2. The active working plan is synced to `GSD_PLAN.md` at the project root.
3. Completed phase plans are archived to `.gsd/history/` or timestamped within `plans/archive/`.
