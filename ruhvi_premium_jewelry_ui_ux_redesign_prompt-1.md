# Ruhvi — Premium Jewelry Website UI/UX Redesign Prompt

## Project Goal

Redesign the existing **Ruhvi jewelry e-commerce website** with a sophisticated, premium, editorial and modern visual identity.

The goal is **not to rebuild the website's functionality from scratch**. Keep all existing features, business logic, product functionality, authentication, cart, checkout, account functionality and existing integrations intact.

This project is primarily a **UI/UX transformation** focused on visual quality, hierarchy, usability, product presentation and overall user experience.

---

## Design Inspiration

Use these two websites as **visual and UX references**:

- https://www.foramour.com
- https://rasasilver.com

Study their:

- visual richness
- product photography
- image placement
- editorial layouts
- typography
- spacing
- product presentation
- video usage
- category presentation
- navigation patterns
- premium brand feeling
- balance between photography and whitespace

**Do not copy** their design, colors, layouts, branding, typography or exact components.

Instead, extract the best design principles from both references and create a completely original visual language for **Ruhvi**.

The final result should feel like a premium jewelry brand with its **own identity**, not a clone of either reference.

---

# 1. Overall Brand Direction

The website should immediately communicate:

- Premium
- Elegant
- Modern
- Refined
- Trustworthy
- Fashion-forward

Avoid making the website look:

- cheap
- overly commercial
- discount-oriented
- overly colorful
- generic
- template-like
- excessively dark
- excessively white/minimal
- overly luxurious in a stereotypical way

Do not position Ruhvi around affordability.

Avoid messaging such as:

- “Luxury at an affordable price”
- “Luxury without the luxury price”
- “Cheap luxury”
- aggressive discount messaging

The brand should feel premium because of its **visual language, craftsmanship, photography and experience**, not because it repeatedly talks about price.

---

# 2. Color Direction

Do **not** use pure black as the primary theme.

Avoid:

- pure black backgrounds
- extremely dark navy
- overly dark luxury themes
- completely white sterile layouts
- excessive gold everywhere

Instead create a **medium-light rich premium palette**.

The palette should have depth and richness while remaining bright enough for jewelry photography.

Suggested direction:

- Warm champagne / soft ivory for primary backgrounds
- Rich pearl beige for secondary sections
- Soft muted taupe for supporting surfaces
- Warm charcoal for typography instead of pure black
- Refined muted gold/champagne-gold for accents
- Very subtle warm metallic accents
- Optional extremely subtle muted green or burgundy accent only where appropriate

The overall appearance should sit between:

**light luxury + rich editorial sophistication**

The color system must make gold, silver, stones and jewelry details stand out beautifully.

---

# 3. Product Photography Is the Hero

Photography should be one of the most important elements of the entire website.

The UI should be designed **around the jewelry**, not around decorative UI elements.

Product images should:

- have enough breathing room
- remain visually dominant
- use clean backgrounds
- show fine jewelry details
- support close-up photography
- include lifestyle/model photography where appropriate (using Indian models exclusively)
- feature exclusively gold plated products (do not show other materials)
- create visual storytelling
- feel editorial rather than like a basic catalog

Use a combination of:

1. Product-only photography
2. Close-up detail photography
3. Jewelry worn by Indian models
4. Lifestyle photography
5. Editorial photography
6. Short product/content videos
7. UGC/customer content where appropriate

Avoid filling every section with cards.

Use large editorial compositions where they create more impact.

---

# 4. Header / Navigation

Create a clean premium header.

Desktop:

**Logo | Navigation | Search | Wallet | Wishlist | Cart | Profile**

The exact positioning can be optimized for UX, but the hierarchy must remain clean and uncluttered.

## Wallet

Add a dedicated **Wallet icon**.

Position:

**Wallet → Wishlist → Cart → Profile**

The wallet should appear **before Wishlist**.

The wallet icon should have a small balance badge.

Examples:

- `₹50`
- `₹161`

If the balance becomes very large, use a compact format only when necessary.

The wallet balance badge should feel like a notification badge, but remain elegant and integrated into the premium design.

Do not make it look like a promotional sticker.

The first-time signup experience should provide the user with:

**₹50 signup wallet bonus**

The UI should clearly but elegantly communicate this to the new user.

---

# 5. Hero Section

Create a visually powerful hero section.

The hero should use either:

- cinematic jewelry photography
- or a short, elegant content video

The jewelry must remain the primary focal point.

The hero should not contain too much text.

Recommended structure:

**Large visual → Short brand statement → Primary CTA → Secondary CTA**

Possible messaging direction:

- “Designed to be remembered.”
- “Elegance, made personal.”

Do not use aggressive sales language.

Possible CTAs:

- **Explore Collection**
- **Discover New Arrivals**

The hero should feel editorial and cinematic.

---

# 6. Featured Collections

Immediately after the hero, introduce major collections using large visual blocks.

Do not create a boring standard 4-column product grid.

Use editorial layouts such as:

- large feature image + smaller supporting image
- asymmetric grid
- large horizontal collection cards
- full-width visual sections
- image + text compositions

Each collection should feel like a visual story.

---

# 8. New Arrivals

Create a visually refined New Arrivals section.

Use product cards with:

- large product image
- product name
- price
- subtle wishlist interaction
- quick view where appropriate
- hover image change
- subtle interaction animation

Keep product cards clean.

Do not overload cards with badges.

Use promotional badges only when genuinely necessary.

---

# 9. Best Sellers

Create a Best Sellers section with strong visual hierarchy.

Use fewer, larger products rather than squeezing too many products into the viewport.

The section should feel curated.

Example title direction:

**“The Pieces Everyone Loves”**

Then show selected products.

---

# 10. Editorial / Lifestyle Content

This is an important differentiator.

Introduce lifestyle/editorial sections where jewelry is shown in context.

Use:

- model photography
- close-up shots
- fashion styling
- lifestyle scenes
- premium editorial photography

The purpose is to answer:

**“How does this jewelry actually look when worn?”**

The jewelry should feel aspirational but still believable.

---

# 11. Content Video

Integrate short-form content videos naturally into the website.

These should **not** feel like random advertisements.

Use videos to show:

- jewelry movement
- how pieces look when worn
- close-up craftsmanship
- styling
- packaging
- lifestyle moments
- product details

Use large cinematic video sections rather than tiny embedded boxes when appropriate.

Keep autoplay muted where suitable.

Ensure the UI still performs well on mobile.

---

# 12. UGC Section

Create a tasteful UGC section.

Possible titles:

- **“Seen on You”**
- **“Styled by You”**

Show real customer content in a visually consistent way.

Use:

- customer photos
- short customer videos
- Instagram-style content
- product tagging

Do not make this section look like a social media feed pasted onto the website.

It should still feel consistent with the premium brand identity.

---

# 13. Product Detail Page

The product page should receive significant UX attention.

Prioritize:

- large product photography
- image gallery
- zoom
- video when available
- model/lifestyle image
- product details
- price
- variant selection
- quantity
- Add to Cart
- Buy Now
- Wishlist
- wallet balance/use where applicable
- delivery information
- returns
- care information
- trust information

Include rich media without making the page visually chaotic.

The product should remain the hero.

---

# 14. Product Image Experience

Improve the image gallery substantially.

Include:

- large primary image
- thumbnail navigation
- zoom
- image switching
- video thumbnail when available
- lifestyle/model image
- detail/close-up image

On mobile, use a swipeable gallery.

The transition between images should be smooth and premium.

---

# 15. 360° Product Preview

Where technically supported, introduce a **360° product preview**.

The interaction should feel subtle and premium.

Do not force the feature on products that do not have 360° assets.

---

# 16. Wallet UX

The wallet is an important new UX element.

Header:

**Wallet icon + live balance badge**

Examples:

- `₹50`
- `₹161`

When clicked, open a refined Wallet interface.

Show:

### Available Balance

**₹50**

Then:

- Wallet history
- Signup bonus
- Wallet credits
- Wallet debits
- Expiry information if applicable
- Amount used during checkout

If supported by the existing backend, allow the user to apply wallet balance during checkout.

The wallet should feel like a native part of Ruhvi, not a third-party payment widget.

---

# 17. Trust Section

Create a subtle trust-building section.

Possible elements:

- Quality Assured
- Secure Payments
- Easy Returns
- Reliable Delivery
- Authentic Products
- Customer Support

Keep this section visually subtle.

Do not turn it into a large icon-heavy banner.

- design philosophy
- attention to detail
- quality
- styling

Do not talk about being “cheap” or “affordable luxury.”

The goal is to explain:

**Why should someone choose Ruhvi?**

# 22. Typography

Use an elegant typography pairing.

## Headings

A refined editorial serif or sophisticated high-contrast serif.

## Body / UI

A clean modern sans-serif.

The typography should feel:

**fashion editorial + modern e-commerce**

Avoid overly decorative fonts.

Prioritize readability.

---

# 23. Animations

Use animation carefully.

Recommended:

- smooth image transitions
- subtle hover effects
- gentle fade/slide reveals
- product image zoom
- smooth menu transitions
- subtle wallet badge animation
- elegant button hover states

Avoid:

- excessive parallax
- flashy animations
- bouncing elements
- aggressive gradients
- distracting motion

The animation should communicate **quality**, not “look what the developer can do.”

---

# 24. Mobile UX

Design mobile-first.

The mobile experience is extremely important.

Use:

- sticky header
- clean navigation
- easy search
- wallet
- wishlist
- cart
- profile
- bottom navigation where appropriate
- swipeable product galleries
- large product imagery
- touch-friendly buttons
- fast interactions

Do not simply shrink the desktop layout.

Create a genuinely optimized mobile experience.

---

# 25. Existing Functionality

**IMPORTANT: Do not remove or redesign away existing functionality.**

Preserve all existing:

- features
- product functionality
- authentication
- account system
- cart
- checkout
- order system
- existing integrations
- existing backend logic
- existing APIs
- existing database behavior

The redesign should primarily change:

**UI + UX + visual hierarchy + interaction design + presentation**

The goal is to make the existing website feel like a much more premium product without breaking its existing functionality.

---

# 26. Design Philosophy

The final design should feel like:

**A modern premium jewelry editorial experience combined with a highly usable e-commerce store.**

It should NOT feel like:

- a generic Shopify template
- a discount store
- an overly dark luxury website
- a minimalist website with no personality
- a marketplace
- a copy of Foramour
- a copy of Rasa Silver

The product photography should always remain the star.

Every section should have a clear purpose.

Use whitespace strategically, but maintain enough visual richness that the website never feels empty.

---

# 27. Final Visual Goal

When a user lands on Ruhvi, the first impression should be:

**“This is a premium jewelry brand.”**

Then:

**“The products look beautiful.”**

Then:

**“The website is easy to explore.”**

Then:

**“I trust this brand.”**

And finally:

**“I want to see more products.”**

Create the design system, homepage layout, responsive behavior, component hierarchy, typography, color system, spacing system, buttons, cards, navigation, product presentation and interaction patterns around this goal.

The final design must be:

**original, premium, product-focused, editorial, rich but not dark, elegant but not sterile, and conversion-friendly without looking sales-heavy.**
